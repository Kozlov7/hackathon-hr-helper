# HR-помощник: от заявки руководителя к вакансии

ИИ-сервис (GigaChat + Streamlit): сравнивает заявку руководителя с похожими вакансиями рынка
и оформляет вакансию в формате компании (АО «ИРЗ» на hh.ru).

## Три шага
1. **Заявка** — загрузить .docx/.txt, взять пример или вставить текст; текст можно править.
2. **Аналитика рынка** — два блока: «Есть на рынке — нет у нас» и «Есть у нас — на рынке иначе».
   У каждого пункта — сколько вакансий из похожих, примеры с цитатами и вопрос руководителю.
   Вопросы можно скопировать или скачать. Поправили заявку — сравните заново.
3. **Вакансия** — карточка в стиле hh.ru, редактирование, выгрузка в HTML (оттуда — печать в PDF),
   Word и HTML-описание для вставки на hh.ru. Внизу — что из заявки не попало в публикацию и почему.

Как отбираются вакансии: ① фильтр по названию должности (варианты подбирает ИИ по заявке) и городу — без ИИ;
② GigaChat оценивает похожесть по смыслу; в сравнение идут вакансии от 50%.
Цифры «в N из M» считает Python, ИИ только сопоставляет требования по смыслу.
Вакансия не придумывает значений: только то, что есть в заявке; пропуски пунктов проверяются кодом.

## Запуск
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        # вписать ключ GigaChat
.venv/bin/streamlit run app.py
```
Без ключа работает демо-режим на сохранённых ответах для примера заявки.

## Данные
- `data/vacancies/*.txt` — база вакансий: шапка (ссылка, компания, зарплата…), строка `---`, текст.
- `data/template_irz.txt` — формат вакансий ИРЗ на hh.ru.
- `data/cache/` — разобранные ИИ вакансии (создаётся сама, пересоздаётся при изменении текста).

## Файлы
`app.py` — страница · `llm.py` — GigaChat · `parse.py` — разбор заявки и вакансий ·
`compare.py` — сравнение с рынком · `generate.py` — вакансия, HTML/Word, вопросы руководителю.
