# HR-помощник: от заявки руководителя к вакансии

ИИ-сервис (GigaChat + Streamlit) для HR: разбирает заявку руководителя, сравнивает её с вакансиями рынка,
предлагает вопросы руководителю и собирает текст вакансии по шаблону компании.

## Шаги
1. **Заявка** — ИИ определяет профиль позиции, раскладывает заявку по пунктам и находит то, что нельзя публиковать.
2. **Рынок** — ИИ оценивает похожесть вакансий из базы; HR может включить/исключить вакансию или добавить свою.
3. **Сравнение и рекомендации** — ИИ сопоставляет требования по смыслу, Python считает «в N из M»;
   список «стоит уточнить» и письмо руководителю (.txt/.docx).
4. **Вакансия** — текст по шаблону ИРЗ, редактирование, проверка на соответствие заявке, выгрузка .txt/.docx.

Вакансия собирается всегда: пробелы не заполняются выдуманными значениями.

## Запуск
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        # вписать ключ GigaChat
.venv/bin/streamlit run app.py
```
Без ключа приложение работает в демо-режиме на сохранённых ответах для примера заявки.

## Данные
- `data/vacancies/*.txt` — база вакансий: шапка (ссылка, компания, зарплата…), строка `---`, текст вакансии.
- `data/template_irz.txt` — шаблон вакансии компании.
- `data/cache/` — разобранные ИИ вакансии; создаётся автоматически, пересоздаётся при изменении текста.
- `data/demo/` — ответы для демо-режима.

## Файлы
`app.py` — страница · `llm.py` — GigaChat · `parse.py` — разбор заявки и вакансий ·
`compare.py` — сравнение с рынком · `generate.py` — текст вакансии, проверка, письмо.
